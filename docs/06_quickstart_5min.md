# 5-Minute Newcomer Quickstart

Author: Oblx <code@oblx.dev> | Package Lock: `@chronos-ui/svelte` (`v0.0.7`)

## Minute 1 — Install and Launch Locally

1. Clone the repository and run `bun install` (zero runtime dependencies exist inside `@chronos-ui/svelte`).
2. Start the local workbench with `bun run dev` and open `http://localhost:3000`. You land on the Calm Empty Stage with the 21-state `Cyber Reticle` CSS cursor active — zero API keys and zero login required.

## Minute 2 — Launch Samples or Build Shapes

1. Launch any of the five starter samples (`Neon Ops Command Deck`, `Bio-Telemetry Lab`, `Synth Audio Console`, `Writer's Focus Cockpit`, or the 14-shape nested `Shape Matrix Lab`).
2. Or click `[ + Build ]` in the top-right bar to place cards, navbars, charts, tables, or UML containers directly onto your canvas.

## Minute 3 — Calibration Console, Station Builder & Zone Edition

1. Open `Settings -> Visuals & Motion` to calibrate `Corner Radius` (`0.25rem–1.5rem`), toggle `STRAIGHT | CHAMFER | ROUND`, and test embellishments, motion transitions, and curved ROUND arcs inside the centered Live Preview Cartridge.
2. Open `Station Builder` or `Zone Edition` (`[ Stations ]` / `[ Zones ]` in top bar or `Edit Zone` in Bento Radar) to tune architectural layers, toggle bilateral $X = 50\text{vw}$ corner mirroring, and relocate entities across all 11 perimeter zones.

## Minute 4 — 21-State Cursor Studio & 33-Tool MCP Parity

1. Open `Cursor Studio` to switch between 4 curated 21-state packs, upload a `<= 128 KB` PNG, calibrate its hotspot, or synthesize all 20 secondary CSS cursor states.
2. Mint a CLI PAT (`bun run mcp:token`) or run `bun run mcp:stdio` to drive all 33 parity tools headlessly or via live Twin sessions.

## Minute 5 — Lean QA & Static App Export

1. Click `Export` (or call `ui_export_static`) to compile a production Vite static bundle including `--ui-corner-cut` and your active 21-state cursor CSS.
2. Run `bun run qa:fast`, `bun run qa:delta`, and `bun run qa:release` (with `bun run qa:timer -- start 45`) to verify all static invariants, 9 test suites, and production builds.
