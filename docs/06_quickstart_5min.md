# 5-Minute Newcomer Quickstart

Author: Oblx <code@oblx.dev> | Package Lock: `@chronos-ui/svelte` (`v0.1.0`, MIT License)

## Minute 1 — Install and Launch Locally

1. Clone the repository and run `bun install` (zero runtime dependencies exist inside `@chronos-ui/svelte`).
2. Start the local workbench with `bun run dev` and open `http://localhost:3000`. Studio boots unconditionally in Calm Mode with the concrete-hex 21-state `Cyber Reticle` cursor, framed bilateral edge rails, and flush `UiAssistantDock` — zero API keys required.

## Minute 2 — Launch Samples or Converse with Builder Assistant

1. Hover any starter sample chip (`Neon Ops Command Deck`, `Bio-Telemetry Lab`, `Synth Audio Console`, `Writer's Focus Cockpit`, or `Shape Matrix Lab`) to preview wrapped multi-paragraph vector tooltips, or click one to assemble live Svelte 5 components.
2. Unfold `UiAssistantDock` (`OVERLAY_HOVER`, $0\text{px}$ canvas shrinkage), type a prompt, and submit: discrete `[OK]` tool chips appear beneath a sticky header while the primary CTA transitions deterministically from `Build` to `Send`.

## Minute 3 — Reciprocal Studio HUD, Calibration & Zone Edition

1. Click the centered `Studio HUD` / `Calm View` anchor ($X = 50\text{vw}$, $\Delta x \le 16\text{px}, \Delta y \le 8\text{px}$) to toggle full 11-zone telemetry chrome without moving the pointer, and use the unified top-left `ProjectLifecyclePod` (`Save` + `Reset` popover).
2. Open `Station Builder`, `Zone Edition`, or `Wireframe Skeleton Workbench` (`Alt+M` for state-preserving Grow/Shrink) to calibrate 3-tier corner cuts (`0.25rem–1.5rem`), bilateral mirrors, and all 14 shapes.

## Minute 4 — 21-State Cursor Studio & 42-Tool MCP Parity

1. Open `Cursor Studio` to switch between 4 curated 21-state packs, upload a `<= 128 KB` PNG, calibrate hotspots, or derive all 20 secondary CSS states with automatic `dark <-> light` polarity recoloring.
2. Mint a CLI PAT (`bun run mcp:token`) or run `bun run mcp:stdio` to drive all 42 parity tools headlessly or over live Twin sessions.

## Minute 5 — Granular Subpaths, Lean QA & Static/Full-Stack Export

1. Import `@chronos-ui/svelte` or any of its `13` granular subpath barrels (`./tokens`, `./wire`, `./machines`, `./atoms`, `./organisms`, `./assistant`, etc.) with verified `.d.ts` declarations.
2. Run `bun run qa:fast` ($\le 2.5\text{s}$ warm incremental check) and `bun run qa:harness --json` (scoped `--scenario=latest`) during development, reserving `bun run qa:release` for final sign-off.
