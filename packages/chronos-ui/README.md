## Overview

`@chronos-ui/svelte` is a zero-dependency Svelte 5 Runes perimeter HUD presentation framework built around parametric chamfer and concentric round true-stroke vector borders (`UiVectorBorder`), an 11-zone bilateral HUD shell (`UiPerimeterHud`), elevated zero-shrinkage overlay edge drawers (`UiEdgeDrawer`), an ADHD-friendly `CALM_SLOW` global motion token engine, a 21-state concrete-hex CSS cursor runtime, 14 UML/diagram frame shapes, RFC 9562 UUID v7 `$state.raw` O(1) entity telemetry, gesture-coalesced stage pan/zoom, and an acyclic DAG wire broker.

## Installation & Quick Usage

1. Install alongside Svelte 5: `bun add @chronos-ui/svelte` (or `npm install @chronos-ui/svelte`).
2. Import `@chronos-ui/svelte/styles.css` once in your application root entry.
3. Import components and utilities from `@chronos-ui/svelte` or any of the 13 tree-shakeable subpath barrels above.
